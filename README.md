# ExpertSoft
ExpertSoft is a web application that specializes in database management for a software company that develops products for the electrical sector in Colombia. This application is developed using JavaScript and MySQL Workbench.

# Features
View a dashboard with customer, transactions and invoices reports.
Operations management: add, edit, and delete customer, transactions and invoices reports.

# Isntallation And Execution
1. Clone the repository:
git clone https://github.com/giselle-01/ExpertSoft.git

2. Install the dependencies:

npm install

3. Start the development server:

node server/connection_db.js

# Technologies Used

-JavaScript
-MySQL Workbench
-Vite for development and build
